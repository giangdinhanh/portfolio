# Animated Portfolio for GitHub Pages

A static animated portfolio inspired by the supplied CV landing-page composition.

## Publish
1. Create a GitHub repository.
2. Upload every file and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then `main` and `/root`.

## Customize
Edit the name, text, links, and email in `index.html`. Replace the SVG files in `assets/` with your own images while keeping the filenames, or update the paths in the HTML.

Motion includes layered parallax, floating decorative objects, morphing portrait mask, orbit rings, text entrances, magnetic buttons, 3D card tilt, scroll reveal, and reduced-motion support.

## Interactive hero files
The hero now starts with `assets/hero/data-matrix.jpg.png`. Moving the cursor reveals `city-preview.png` through a soft radial mask. Double-clicking the hero, pressing Enter, or using the Explore button opens the seven-layer parallax city.
